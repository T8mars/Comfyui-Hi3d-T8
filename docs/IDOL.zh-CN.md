# Idol 图片生成高斯与网格

Idol 已接入独立 v0.6 工作台，使用隔离运行时；真实生成、加工、下载、取消及恢复已验证。网页原始高斯操作、网格／PBR 导出和一份完整 4 秒角色动作播放也已通过，实测范围与质量限制见下文回执。ComfyUI-Hi3D 自定义节点继续只提供 Hi3D 精修。

在「图片建模」中选择 **Idol · 高斯与彩色网格**，上传一张主体完整的图片。透明背景会直接使用原 alpha；自动前景使用 BiRefNet。生成图／渲染图使用官方 1.2 裁切边距，真实照片选项使用 1.7 边距。实际条件图与预测输入相机均保存。

默认使用原生 Euler 的 50 步时间表和引导公式，随机数与编码由固定 Comfy 后端执行；这不代表与原 SDK 逐值相同。也可选择官方 Comfy 模板的 DPM++ 2M／20 步。两种方案的引导值口径不同，不能只按相同种子和数字认为等价。当前角色实测 Euler 的结构明显更完整，失败对照也保留在验证目录。

默认 262144 个高斯。较高数量增加密度和资源开销，不保证新增细节。「仅高斯」时关闭网格提取，同时不运行 Hi3D 或 PBR；原始 PLY、SPZ、KSPLAT 均可下载，在独立高斯预览中拖动旋转、缩放和平移。可另存 75 帧／25fps／512² 的静态物体环绕展示视频。

勾选「同时提取彩色网格」可得到顶点色、无光照材质的 GLB。默认使用独立保存的新版官方表面提取模块，也保留旧版密度表面对照。内部壳层处理会改变表面；开口保留强度较小时可能封住杯口、衣领等开口。原始高斯保持并单独保存，转换失败仍可下载。

网格正面默认按预测输入相机的水平方向对齐到 glTF +Z，保留竖直轴；相机、实际矩阵与原始高斯分别记录。可以关闭此项保留官方提取坐标。选择 PBR 贴图后，另由所选贴图引擎为网格生成 UV 和材质；无光照顶点色本身不宣称含金属度／粗糙度贴图。合格网格可进入资产加工页继续减面、拆件、绑定和单人动作，各项质量依实际结果判断。

模型按固定版本和 SHA256 管理，Idol／decoder／DINO-H+／FLUX.2 VAE／BiRefNet 共约 3.78 GB，不含 Python、依赖和缓存。已有同哈希 VAE 可通过硬链接复用，无需重复下载。DINO-H+ 与既有 TRELLIS.2 的 DINO-L 不能互换。

Idol 单独安装使用自己的 BiRefNet，不额外要求 U2Net。启用 PBR 时，贴图阶段仍按原有规则检查自动前景与贴图模型；这些模型体积另计。完整包已包含并校验所选组件。

开发环境准备：

```powershell
.\.pipelineenv\Scripts\python.exe -m hi3d_workbench.pipeline_models download --selection engine:coarse:idol
.\.pipelineenv\Scripts\python.exe tools/setup_idol_runtime.py --validate-image samples/sculpted-vase.png
```

私有依赖放在 `engines/idol`，新版网格模块放在 `sources/idol_mesh`；不原地升级原 Torch、Diffusers 或 UltraTex 使用的 Comfy 核心。运行时只从本地模型路径加载，任务受现有进度、取消及重启恢复机制控制。运行环境就绪回执必须绑定真实成功生成和输出哈希后登记。

上述命令用于开发环境；完整整合包使用随包提供并验证过的私有运行时。`--validate-image` 会真实生成一份网格并登记就绪，产物留在 `data/idol-runtime-validation`。这一步用于检查安装，不代表该图片的建模质量验收通过。

本机验证使用 RTX 5090 Laptop 24GB，记录为不同范围的实际任务，不能直接当作同条件性能排名：

默认网格仍有 77 条非流形边，不能据“生成成功”判断可打印。Hi3D 可改变脸部与衣物外形，请对照原始彩色网格选择是否采用精修；默认不会自动开启 Hi3D。出拳样例存在少量达到拉伸诊断阈值的三角面，也不代表动作自然度、碰撞和所有角色均已验收。

发布前整仓 935 项测试通过，另有发布流程独立目录的更新器验证，见[发布前检查](../validation/v060-publication-checks.json)。源码与产物哈希见 [整合验证回执](../validation/idol-integration-2026-11-08.json)。实际网页已检查百万高斯显示／旋转／缩放、参数复用、三种原始格式下载哈希、网格／PBR 阶段切换及 180mm GLB 导出。资产页缺失的同版本 Three.js HDR 依赖已补齐并增加模块加载回归。Chrome 自动上传仍需用户自行授予扩展文件 URL 权限，自动下载事件捕获未通过；上传与下载已通过内置浏览器验收，详见 [网页回执](../validation/idol-browser-2026-11-08.json)。
