# 多视图建模

[English](MULTIVIEW.md) | **简体中文**

仅用于独立工作台和完整整合包。ComfyUI 节点继续只运行 Hi3D 几何精修。

1. 在「图片建模」选择 **Hunyuan3D-2mv · 多视图**，在主图片位置上传正面。
2. 分别上传同一物体的左侧、背面或右侧。三视图可使用正面＋左侧＋背面，也支持按需提供其他组合；正面为主参考。
3. 各视图保持一致的外形、比例和方向。每张图片会独立处理前景；透明 PNG 也可直接使用。
4. 默认使用 384 几何分辨率、30 步，省显存模式按阶段搬运模型。可选择后续 Hi3D 精修和 PBR 贴图；**现有精修、贴图阶段使用正面参考**。
5. 历史任务保存所有视图，可预览、下载原图或点击「复用输入」继续调整。原图缺失时会提示并拒绝不完整复用。

首次选择后，在「模型与环境」准备对应引擎。新增 FP16 权重约 **4.93 GB**，默认位于 `models/extensions/coarse_hunyuan_mv/`；自定义模型根目录同样生效。权重中包含该多视图模型的几何、VAE 和图像条件组件，不能替换成单图 2.1 或 mini 权重。

UV 自动展开会保留原坐标、法线和有效有向三角面。原生图集不合格时，可明确记录原因并独立重试一次 GPU 图集，仍执行相同退化、重复和局部修复上限检查；再次失败会停止，原几何保留，不静默整网转 CPU 重算。零面积退化面单独计数。

多视图会提供更多几何约束，不能保证所有输入都准确还原隐藏结构，也不是带标定相机的摄影测量。请检查侧面、背面和最终材质。

来源：[官方模型](https://huggingface.co/tencent/Hunyuan3D-2mv)、[官方三视图示例](https://github.com/Tencent-Hunyuan/Hunyuan3D-2/blob/main/examples/shape_gen_multiview.py)。固定模型版本及文件清单位于 `hi3d_workbench/pipeline_models.py`；分发保留原 Tencent Hunyuan 3D 2.0 社区许可。
