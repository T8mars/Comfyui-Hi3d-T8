## 中文

独立整合包新增程序自动更新：空闲时检查并下载 GitHub 正式版本，通过 SHA256 校验后在下次启动时安装。安装有代码备份、失败恢复和中断恢复，保留模型、Python 环境、配置和历史任务。

**本页只提供代码，不包含模型权重、Python 或运行环境。含模型与 Python 的完整版由 T8star 另行提供。**

- `ComfyUI-Hi3D-nodes-0.4.1.zip`：节点与可视化画布工作流，仍只调用 Hi3D 几何精修。
- `Hi3D-Workbench-source-0.4.1.zip`：源码，需要自行准备环境和模型。
- `Hi3D-Workbench-update-0.4.1.zip`：覆盖已有 v0.4.0+ 完整工作台的代码；不能单独运行。旧 v0.4.0 先关闭程序、解压覆盖一次，之后支持自动更新。
- `update-manifest.json` / `SHA256.json`：自动更新清单和下载校验。

后续新增的建模、贴图及辅助权重统一补充到 [Hugging Face 模型仓库](https://huggingface.co/t8star/Hi3d-Comfy)，与程序分开下载。UltraTex 的 FLUX.2 Klein 9B 底座为非商业许可。

[更新说明](https://github.com/T8mars/Comfyui-Hi3d-T8/blob/main/docs/UPDATES.zh-CN.md)

## English

The standalone bundle now checks and downloads stable GitHub code updates while idle, verifies SHA256, and installs on the next launch. Code backups and rollback preserve models, Python runtimes, configuration and job history.

**Release downloads contain code only, with no weights, Python interpreter or runtime. T8star will provide the complete package separately.**

The node ZIP contains Hi3D-only nodes and the visual canvas workflow. The source ZIP requires a separately configured environment. The update ZIP overlays an existing v0.4.0+ workbench and cannot run alone. For the first v0.4.0 upgrade, close the app and extract the update ZIP over its root; subsequent updates are automatic. Model downloads are hosted separately on Hugging Face. Runtime-incompatible updates require a new complete package.

[Update instructions](https://github.com/T8mars/Comfyui-Hi3d-T8/blob/main/docs/UPDATES.md)
