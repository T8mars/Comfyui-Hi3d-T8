# Hi3D T8 v0.4.2

Windows 整合包增加可见 EXE 启动器。日志窗口保持打开，启动失败保留错误；支持 Ctrl+C、关闭窗口、网页「关闭工作台」及停止脚本。启动器退出时清理所属服务和推理子进程，重复启动复用本目录服务，端口冲突时不操作其他目录的程序。浏览器在服务就绪后打开。侧栏与页尾加入 T8star 的七个社媒和资源入口。

The Windows bundle gains a visible console launcher with process-tree cleanup, explicit shutdown controls, duplicate-instance detection and browser opening after readiness. Startup failures stay visible. The workbench includes T8star community links. ComfyUI nodes and the visual workflow remain Hi3D geometry-only.

GitHub 提供源码、节点、代码更新包及独立启动器 ZIP，**不含模型权重、Python 或运行环境**。完整整合包由作者另行提供。`Hi3D-Workbench-launcher-0.4.2.zip` 先配合 v0.4.2 代码更新使用，解压到整合包根目录；缺少 EXE 时新版启动脚本也可使用 Windows .NET Framework 4 编译器构建。代码自动更新仍兼容 v0.4.1，不更换 Python 或模型。启动器源码随仓库提供，EXE 未签名。

GitHub assets contain code and the small launcher only. Python and weights remain in the separately distributed complete bundle. Apply the code update before extracting the launcher ZIP; or let the updated start script build a missing launcher with Windows' .NET Framework 4 compiler.
