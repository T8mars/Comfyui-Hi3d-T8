# Hi3D T8 v0.4.3

Windows 整合包附带可见 EXE 启动器，保留日志窗口，提供 Ctrl+C、关闭窗口、网页关闭按钮与停止脚本。重复启动复用本目录服务，关闭时释放所属推理子进程；侧栏与页尾附带七个社媒资源入口。ComfyUI 节点和画布工作流保持 Hi3D 几何精修接口。

此版修复首次自动升级的 Windows 兼容问题：由稳定的启动监督进程先安装代码，再用全新解释器启动服务，避免旧版 `os.execv` 提前结束原进程导致服务被一并清理。v0.4.2 标记为预发布，请使用 v0.4.3。

The visible Windows launcher preserves logs, owns its subprocess tree, supports explicit shutdown and reuses the same directory's service. This release fixes first-update startup on Windows: a stable supervisor installs the overlay before starting a fresh server interpreter, keeping the process-tree owner alive. v0.4.2 is a prerelease; use v0.4.3 instead.

GitHub 附件只有源码、节点、程序更新包和独立启动器 ZIP，**不含模型权重、Python 或运行环境**。完整版由作者另行提供。已有整合包先安装对应代码更新，再将 `Hi3D-Workbench-launcher-0.4.3.zip` 解压到根目录。新版启动脚本在缺少 EXE 时也可使用 Windows .NET Framework 4 编译器构建。EXE 源码随仓库附带，未做数字签名。

GitHub assets contain code and a small launcher only. Python and models are distributed separately. Apply the matching code update and extract the v0.4.3 launcher into the bundle root. The launcher is open source and unsigned.
