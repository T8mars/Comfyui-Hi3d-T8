# Hi3D T8 v0.4.4

完整工作台增加 **UltraTex · INT8 ConvRot Base 9B**，保留 FP8 Base 9B 独立选项。使用固定 CivitAI 版本、文件大小与 SHA256，原生加载 `int8_tensorwise + convrot`，继续使用原始 UltraTex 适配器与前景 VAE。不是 distilled/KV 模型，不重新量化，保留原始 FLUX 非商业许可。INT8 不保证在每种 GPU 上比 FP8 更快或更省显存。

修复“默认组件就绪”与“全模型整合包”的混淆。模型页显示引擎就绪数量，增加“补齐全部引擎（含 INT8）”。全模型覆盖包含 Hi3D 核心和 14 个扩展组件，支持三个建模与四个贴图选项；打包必须使用 `--include-models --include-pipeline --all-engines`，并写入 `full_engine_coverage`。公共模型下载改为分块落盘，限制响应大小并校验 SHA256，避免一次性读入大模型占满内存。

Adds a separate UltraTex INT8 ConvRot **Base 9B** option, retaining FP8, with pinned source/size/hash and native quantized loading. The model page reports engine coverage and can prepare all dependencies. Full-model builds explicitly use `--all-engines`; baseline-only packages are not called complete. Public artifact downloads stream to disk with size/hash validation. ComfyUI nodes and visual canvas workflows remain Hi3D-only.

省显存模式下，UltraTex 在显存足够时先用 GPU 编码 Qwen 条件，随后卸载再加载扩散底座；显存不足继续使用 CPU。报告记录实际编码设备和耗时。

GitHub 附件只包含代码与小型 Windows 启动器，不带 Python 或模型。作者另行提供完整整合包；模型与配置可从 Hugging Face 下载，详见双语 README。

验证：328 项回归通过；Windows / RTX 5090 Laptop 24GB 上实际完成 INT8 六视角颜色与材质生成（各 25 步、1024 采样、4K 贴图），嵌入 PBR 的 GLB 与 80mm 导出检查通过。查看了实际 GLB 的正面、侧面和背面渲染。Hugging Face 95 个模型／配置／许可文件远端哈希全部匹配。新控件的浏览器交互未验收；较小显存设备未实测。完整证据见 `validation/v044-int8.json`。
