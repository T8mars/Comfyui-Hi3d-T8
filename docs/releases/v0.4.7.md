# Hi3D T8 v0.4.7

修复独立工作台启动窗口只有标题、没有地址和后续日志的问题。原 EXE 没有显式传递标准输入／输出／错误句柄，Python 服务虽能运行，初始化报错和推理进度却可能不可见。新版显式继承句柄，同时保留 Windows Job Object 对服务和推理进程的退出管理。

启动时显示工作台目录、模型目录和访问地址；同目录 HTTP 会话确认后才提示“就绪”。初始化每隔五秒报告等待状态，自动打开浏览器失败时提供手动地址；无需打开浏览器也会显示就绪消息。

**旧包需同时更新程序代码与本版本 launcher ZIP 内的 EXE**，代码更新器仍不替换二进制。GitHub 附件不含模型或 Python。ComfyUI 节点、模型权重、推理算法和默认参数没有变化。

回归 571 项通过（73.53 秒，1 条依赖弃用警告）。新增测试先复现旧 EXE 丢失输出，再验证标准输出／错误及原有四种进程退出方式；实际嵌入式 Python 经 EXE→启动监督进程→HTTP 服务完成地址、模型目录、就绪日志和认证关闭验证。详细记录见 [启动验证](../../validation/v047-startup.json)。

---

Fixes missing addresses and Python logs in the standalone Windows launcher by explicitly inheriting standard I/O handles. The existing Job Object still owns the server and inference workers. Startup reports directories, URL, verified local HTTP readiness, periodic initialization waits and browser-opening failures.

**Existing bundles need both the code update and this release's launcher ZIP.** The code updater does not replace executable files. GitHub assets contain no models or Python. ComfyUI nodes, weights and inference behavior are unchanged.

All 571 regression tests passed in 73.53 seconds, with one dependency deprecation warning. Real EXE/embedded-Python startup verified stdout, stderr, HTTP readiness, the model-directory message and authenticated shutdown, in addition to the existing four descendant-cleanup cases.
