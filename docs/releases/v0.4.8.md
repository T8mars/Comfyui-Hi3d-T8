# Hi3D T8 v0.4.8

独立工作台优化 TRELLIS.2 核心加载：按阶段载入组件，避免先随机初始化完整参数再覆盖权重；使用保持原始混合精度的 Safetensors 映射与参数赋值。计算生成的旋转位置缓冲区保留，缺少参数时回退原加载器。按需加载不消耗采样随机状态。

新增「按阶段加载，用完释放」与「常驻内存，复用连续任务」选择。默认释放权重；常驻缓存受内存上限和可用内存保护，复用同一路径、文件指纹一致的组件。图片建模和贴图可共用一个推理解释器，减少重复导入；可一键释放常驻模型和运行时。关闭工作台、取消任务、异常退出和切换模型目录均有进程清理。

已完整校验且文件身份未变化的 Hi3D 权重不再每次提交都重新读取计算 SHA256；首次及手动完整校验继续保留。模型文件变化、目录变化或校验记录无效仍会阻止使用。

修复预览可能在 GLB 复制完成前读取到半截文件的问题：阶段文件完成后原子发布，同盘不可变输出优先使用硬链接减少重复复制；先发布整理后的粗模。前端支持有限自动重试与手动重试，并记录本机预览状态。零长、非有限或非单位法线修复后再导出；有效原始法线、顶点、面、UV 和材质保留。

本机同图、种子、512／12 步／百万面预算，几何阶段实测约 54 秒，原任务约 839 秒，原始网格字节完全一致。两次磁盘缓存及 I/O 条件不同，不作为固定倍数承诺。同一 1.3B 模型 CPU 加载对照为 13.761／1.093 秒，641 个参数及缓冲区完全一致，混合精度保持；原加载器先运行，存在缓存先后差异。这些加载与几何测量不代表完整 4K PBR 耗时。

CPU 回归 588 项通过（74.85 秒，1 条依赖弃用警告）。常驻首次、重复、转贴图及释放模式均完成真实 GPU 验证。4 步／10 万面样例首次约 41 秒、重复约 17 秒，原始网格字节一致；小网格贴图约 23 秒。样例规模不同，不与百万面／4K 案例混作速度比较。详见 [验证记录](../../validation/v048-loading.json)。

同图完整百万面／1024 采样／12 步／4K PBR 流程墙钟 406.063 秒，报告 390.23 秒；原任务报告 1667.48 秒，缓存和系统负载条件不同。两个阶段实际使用同一推理进程，完成后已释放，原始网格仍与旧版字节一致。最终 4K GLB 通过标准校验（零错误、零警告）及 Blender CPU 三视角渲染；浏览器自动化未提供浏览器标签页，未声称完成实时浏览器视觉验收。

现有 v0.4.7 启动器可直接使用本次代码更新。没有新增模型或 Python 依赖，ComfyUI 节点和画布工作流仍为 Hi3D 几何精修；GitHub 附件不包含模型或 Python。

---

The standalone TRELLIS.2 loader now loads components on demand, skips overwritten random initialization, and assigns mapped checkpoints while retaining the constructor's mixed precision and computed buffers. Deferred construction preserves sampling RNG. Missing parameters fall back to the official loader.

Choose per-phase release (default) or bounded CPU model residency across jobs, with an explicit unload button. Geometry and texturing share an interpreter; cancellation, shutdown, recovery and model-root changes clean up owned workers. Unchanged, previously verified Hi3D weights reuse identity-bound verification receipts instead of repeated full-file hashing.

Completed stage artifacts are published atomically, with same-volume hard links for immutable outputs. The browser retries failed previews, exposes manual retry and reports local status. Invalid normals are repaired without changing geometry, UV or material content.

The matching 512/12-step/million-face geometry case took approximately 54 seconds versus the original 839 seconds, with byte-identical raw geometry. Disk/cache conditions differed; this is not a universal speed ratio or full 4K PBR duration. A 1.3B CPU checkpoint comparison took 13.761/1.093 seconds with all 641 state tensors exactly equal, measured official-first with a cache-order limitation. Real resident/repeated/texture/release cases passed. See the validation record for scope and limitations.

The complete matching million-face/1024-sampling/12-step/4K PBR run completed in 406.063 wall-clock seconds (390.23 seconds in its pipeline report; the earlier report was 1667.48 seconds under different cache/system conditions). Both stages used one interpreter, which exited afterward. The final GLB passed standard validation with zero errors/warnings and three-view Blender CPU rendering. All 588 CPU regressions passed. Live browser visual inspection remains unverified because no browser automation tab is exposed.

The v0.4.7 launcher remains compatible. Weights, Python dependencies and the Hi3D-only ComfyUI canvas scope are unchanged.
