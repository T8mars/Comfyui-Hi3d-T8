# Hi3D T8 v0.5.0

ComfyUI 改为独立节点：在 ComfyUI 自身 Python／Torch 内运行固定版本官方 Hi3D，无需安装或启动工作台。新增 Model Loader，粗模支持文件上传、拖放和输入目录下拉选择；支持 GLB、PLY、STL。请重新导入新版画布 [Hi3D-Refine.json](../../examples/Hi3D-Refine.json)，旧的简单桥接画布也会提示迁移。节点仍只做「同物体参考图＋粗模→精修几何」，额外建模及贴图引擎仅在独立工作台提供。

工作台默认保留推理解释器、按阶段释放权重，减少连续任务的重复导入；也可选择受内存保护的模型常驻，或任务后退出。新增有界顺序读页、保持原精度的参数加载、完整稀疏形状编码缓存和原始 Telea 四通道并行补边。控制台及页面报告实际阶段与进度。修复短命运行时退出时丢失真实退出码的问题，保留异常清理和孤儿进程保护。

可选 CUDA 体素加速通过「模型与环境」安装固定哈希轮子，不替换 Torch 或原始 o_voxel，含校准、显存保护与 CPU 回退。仅支持已验证的 Windows CPython 3.12／Torch 2.8 CUDA 12.8 扩展运行时；不兼容环境保留 CPU 路径。

本机 RTX 5090 Laptop 24GB／64GB RAM：ComfyUI 真实五节点执行器完成 512／25 步精修与原生 SaveGLB，墙钟 211.69 秒，999,999 面，GLB 零错误／零警告，并完成 Blender 三视角渲染。工作台同参数百万面／4K PBR 首次解释器 231.61 秒、复用解释器 184.16 秒；同网格重复材质 117.78 秒。磁盘缓存未清空，不作为通用倍速承诺。CPU 回归 635 项通过；浏览器自动化没有暴露可控制标签页，未声称完成新版实时画布视觉验收。详见 [验证记录](../../VALIDATION.md)。

GitHub 仅提供代码、节点、代码更新和启动器，不含模型或 Python。现有 v0.4.7 EXE 兼容本次工作台更新；ComfyUI 节点需通过 Manager／Git／节点 ZIP 单独更新。模型文件未改变，完整离线包由作者另行提供。

---

ComfyUI now runs pinned official Hi3D inside its own Python/Torch process. No workbench service is required. A model loader and coarse-mesh file upload, drag-and-drop and input-directory selector replace the HTTP bridge. Import the new canvas example. Nodes remain Hi3D geometry refinement only; additional geometry and PBR engines belong to the standalone workbench.

The workbench retains the interpreter while releasing phase weights by default, with optional bounded model residency or full process release. Bounded checkpoint read-ahead, precision-preserving loading, sparse shape-encoding caching and parallel original Telea channels reduce overhead. Optional, hash-pinned CUDA voxelization preserves the original CPU implementation and Torch installation, with calibration and memory guards. Short-lived runtime failures now retain the actual exit code and cleanup protections.

On the tested RTX 5090 Laptop 24GB/64GB RAM system, the real ComfyUI five-node executor completed 512/25-step refinement and stock SaveGLB in 211.69 seconds. The 999,999-face GLB passed validation and three-view Blender rendering. Matching workbench million-face/4K PBR runs took 231.61 seconds with a fresh interpreter and 184.16 seconds with the retained interpreter. Disk caches were not flushed; these are scoped observations, not universal speed claims. All 635 CPU regressions passed. Live browser canvas interaction remains unverified because no controllable browser tab is exposed.

GitHub assets exclude weights and Python. Workbench overlays and independent ComfyUI node updates are delivered separately. Existing weights and the v0.4.7 workbench launcher remain compatible.
