# Hi3D T8 v0.5.1

独立工作台完善TRELLIS.2加载：用两个16 MiB锁页缓冲交替暂存和异步上传，完成后才进入采样；保持原始精度与随机状态。小模型、自定义/非连续张量和内存保护使用标准路径，锁页失败在修改模型前回退，CUDA执行错误继续报告。终端和网页显示实际上传字节。

新增跨阶段文件预读，在下一阶段准备/UV期间预热所选权重，使用一个8 MiB缓冲及可用内存预算；模型仍按需载入。开始主权重加载时停止后台读取，取消、失败和结束均清理读取线程。

重新核对95个模型/配置/许可文件，共79.27GB，本地与HF哈希一致，无待补传权重。补回本地完整版两份清单声明但缺少的Paint原始编码器文件。中英模型README新增七种引擎的依赖目录、下载体积和组合下载示例，纠正加速轮子的存放说明。

643项CPU回归通过；真实1.3B模型640个状态张量完全一致。四次百万面/4K完整流程按关闭/开启/开启/关闭交替，耗时201.719/158.000/160.969/163.422秒，原始几何字节一致。缓存未清空，不能当作通用倍速。固定同一份网格与形状编码后，两张4K贴图、几何、UV和法线完全一致。GLB校验零错误/零警告，并完成HDR三视角渲染；详细范围见[验证记录](../../VALIDATION.md)。

ComfyUI独立Hi3D节点及画布保持原范围；未加入其他建模/贴图模型。权重、Torch、Python与已有启动器保持兼容，GitHub附件不包含模型或Python。E盘历史NVMe超时尚未确定根因，本次没有更改磁盘、驱动、电源或安全设置。

---

The standalone TRELLIS.2 loader now uses two bounded 16 MiB host slabs for asynchronous weight uploads, preserves precision/RNG, and reports completed bytes. Unsupported layouts and memory guards retain ordinary transfers; errors after CUDA work begins are propagated. One 8 MiB reader can warm selected next-stage files during preparation/UV work and yields when primary loading begins. Cancellation and failure close it.

All 95 model/config/license artifacts (79.27GB) were verified against local manifests and HF hashes; no weights require uploading. Two original Paint encoder files missing from the local full bundle were restored. Bilingual model cards now include complete per-engine download sets and sizes.

All 643 CPU tests passed. A real 1.3B checkpoint retained all 640 state tensors exactly. Four matching full million-face/4K runs took 201.719/158.000/160.969/163.422 seconds with loading optimizations disabled/enabled/enabled/disabled; caches were not flushed. Raw geometry was byte-identical. A separate fixed-mesh/encoding comparison preserved all geometry, UV, normals and both 4K texture arrays exactly. GLB validation and HDR three-view CPU rendering passed.

Native ComfyUI Hi3D nodes, weights and runtimes are unchanged. GitHub assets exclude models and Python. Historical NVMe resets remain a storage diagnostic limitation; no OS/storage settings were modified.
