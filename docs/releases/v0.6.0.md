# Hi3D T8 v0.6.0 · Idol、资产加工与单人动画

独立工作台新增 Idol 单图生成原始高斯与彩色网格，支持 PLY／SPZ／KSPLAT、旋转预览、静态环绕视频和官方网格提取。保留原始高斯、条件图和相机；网格可继续使用 Hi3D、PBR、减面、拆件、绑定和单人动作。另提供 Hunyuan3D-2mv 正面＋左侧／背面／右侧建模。

- 资产加工提供保材质减面、四边面重拓扑、P3-SAM 拆件、X-Part 补全、SkinTokens／UniRig 绑定、动作导入重定向和 Kimodo 单人文本动作。各步骤保留输入、阶段产物和运行报告。
- 真实 HTTP 验证覆盖 Idol 生成至 PBR、六部件拆分、取消／重启保留原高斯及无前景失败。网页实测百万高斯旋转缩放、历史复用、三格式下载哈希、180mm 材质 GLB 导出和一份完整 4 秒／52 关节角色动作；补齐了资产页缺失的同版本 Three.js HDR 依赖。
- 发布前全量 935 项测试通过；更新器在发布流程的独立目录另通过 37 项检查，旧运行时不能误装新代码。
- 项目 Hugging Face 仓库补齐 Idol 和资产加工模型，清单共 169 个权重／配置／许可文件、122.89GB；新增 70 个文件、38.69GB。原始来源、固定版本、许可与哈希保留。**Built with Meta Llama 3**：Kimodo 文本编码使用原始 Llama 3 底座及 LLM2Vec 适配器。

**升级要求：v0.6.0 使用运行时 API 2，旧 v0.5.x 完整包需要换用匹配的新版完整运行时。** GitHub 附件只有源码、节点、代码更新、Windows 启动器和校验清单，不含 Python 或模型；含运行时的整合包由作者另行提供。原有模型可以复用，更新器不会向旧 Python 自动安装新依赖。

ComfyUI 节点与画布继续只提供 Hi3D 几何精修。Idol 默认网格仍存在非流形边，不保证可打印；Hi3D 可能改变脸部与衣物。复杂部件补全、重拓扑、蒙皮与动作仍需逐个检查，不保证所有输入质量；双人动作未加入。更低显存设备和更广泛的照片／机械／薄片／开口基准仍未覆盖。

The standalone workbench adds Idol image-to-Gaussian and colored-mesh generation, native PLY/SPZ/KSPLAT previews/exports, orbit video, official mesh conversion and downstream processing. Hunyuan3D-2mv accepts front and optional side/back references. Asset processing includes material-preserving simplification, quad retopology, segmentation/completion, rigging and single-character animation.

Real generation, processing, cancellation/recovery and offline-path checks are retained. Browser checks verified the million-splat viewer, native download hashes, a 180 mm PBR GLB and complete playback of one four-second, 52-joint character clip. Model manifests cover 169 artifacts/122.89GB, including 70 added artifacts/38.69GB, with original licenses and hashes.

**Runtime API 2 requires the matching v0.6 full runtime bundle for older installations.** GitHub assets contain code and the small launcher, without Python or weights. Native ComfyUI nodes retain geometry refinement only. Complex geometry and motion quality require inspection; printability, universal quality and lower-VRAM compatibility are not guaranteed. Two-character animation is not included.
